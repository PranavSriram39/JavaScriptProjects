# 🚀 JavaScript Beginner Projects

This repository contains simple beginner-friendly JavaScript projects created for practice and learning DOM manipulation, events, and basic logic building.

---

## 📂 Projects Included

### 🧮 Calculator
A basic calculator that performs:
- Addition
- Subtraction
- Multiplication
- Division

Built using HTML, CSS, and JavaScript.

---

### 🕒 Digital Clock
A real-time digital clock that displays the current time and updates every second using `setInterval()`.

---

### 🎯 Number Guessing Game
A simple game where:
- The system generates a random number
- The user tries to guess the number
- Feedback is given (Too High / Too Low)

---

### ✊ Rock Paper Scissors
A mini game where:
- User chooses Rock, Paper, or Scissors
- Computer generates random choice
- Winner is displayed instantly

---

### ⏱ Stop Watch
A stopwatch with:
- Start
- Stop
- Reset functionality

Uses JavaScript timing functions.

---

### 🌡 Temperature Converter
Convert temperature between:
- Celsius
- Fahrenheit
- Kelvin

---

### 🌐 Website Project
A simple responsive website built using HTML, CSS, and JavaScript.

---

## 🛠 Technologies Used
